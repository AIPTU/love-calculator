# 💕 Love Calculator

A beautiful, modern love compatibility calculator built with Next.js, featuring zodiac analysis, detailed breakdowns, and social sharing capabilities. Calculate your love compatibility percentage with stunning animations and share your results with friends!

![Love Calculator Preview](https://via.placeholder.com/800x400/ff6b9d/ffffff?text=Love+Calculator+Preview)

## ✨ Features

### 🎯 Core Functionality
- **Love Compatibility Calculation** - Advanced algorithm considering names, ages, zodiac signs, and more
- **Zodiac Sign Analysis** - Detailed personality descriptions for each zodiac sign
- **Element Compatibility** - Fire, Earth, Air, Water elemental harmony analysis
- **Detailed Breakdown** - See exactly how each factor contributes to your score

### 🎨 User Experience
- **Modern Glassmorphism Design** - Beautiful backdrop blur effects and gradients
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Smooth Animations** - Floating hearts, confetti celebrations, and smooth transitions
- **Dark Mode Ready** - CSS variables support for theme switching

### 📤 Sharing & Export
- **Social Media Sharing** - Share on Facebook, Twitter, WhatsApp
- **Copy to Clipboard** - Easy sharing with one click
- **Shareable Links** - Generate unique URLs that preserve your results
- **Download Images** - Export beautiful result images
- **Print Support** - Print-friendly layouts for physical keepsakes

### 🔮 Advanced Features
- **Real-time Zodiac Calculation** - Accurate birthdate-based zodiac determination
- **Love Tips** - Personalized advice based on compatibility scores
- **Gender Inclusivity** - Support for all gender identities
- **URL Parameter Support** - Load shared results directly from links

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm, yarn, pnpm, or bun

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/love-calculator.git
   cd love-calculator
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   # or
   bun dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) (or the port shown in your terminal)

## 📖 How to Use

1. **Enter Your Information**
   - Fill in your name, gender, and date of birth
   - Do the same for your partner

2. **Calculate Compatibility**
   - Click the "Calculate Love Compatibility" button
   - Watch the confetti celebration! 🎉

3. **Explore Results**
   - View your compatibility percentage
   - Check zodiac sign compatibility
   - See the detailed breakdown
   - Read personalized love tips

4. **Share Your Results**
   - Use social media buttons
   - Copy the shareable link
   - Download as an image
   - Print for keepsakes

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) with App Router
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom CSS variables
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Fonts**: [Inter](https://fonts.google.com/specimen/Inter) via next/font
- **Deployment**: Ready for Vercel, Netlify, or any static hosting
